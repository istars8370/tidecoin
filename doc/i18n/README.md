## Translation policy

1. Preserve exact names, standards, numeric parameters, formulas and links.
2. Do not silently translate technical design proposals into claims of
   currently activated mainnet functionality.
3. Keep terminology consistent: PQC, Falcon, FN-DSA, ML-DSA, ML-KEM, PQHD,
   AuxPoW, YespowerTIDE, UTXO and scrypt.
4. Treat source claims as attributed to the whitepaper; independently verify
   security, quantum-resource and network-uptime claims before publication.
5. Complete chapters 4–15 with paragraph-level source correspondence before
   describing any language edition as a complete translation.
6. Request technical review and native-speaker review before an upstream PR.

Contributions here are intended to help Tidecoin reach international
developers and readers. No changes to consensus, wallet code or token supply.
